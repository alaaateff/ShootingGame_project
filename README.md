# ShootingGame_project
Game Idea
Shooting Fruits : This is a high-speed shooter and target game where the player must shoot objects that shift states quickly. The core mechanic involves shooting "Safe" targets (Fruits) to gain points and avoid "Hazard" targets (Bombs). The game environment is dynamic, with objects constantly switching back and forth between states, testing the player's reflexes and decision-making speed.

Game Objectives

What is the player trying to achieve? 
The player's goal is to accumulate the highest possible Combat Score by successfully hitting safe targets while maintaining their "Hull Integrity" (lives).

Win condition(s): Achieving a new personal best (High Score) which is tracked and saved by the system.
Lose condition(s): -Finish all 3 lives.
-Shooting a target while it is in the "Bomb" state.
-Timer ends
